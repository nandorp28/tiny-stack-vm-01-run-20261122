A tiny stack VM for [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): exact 32-bit wrap, all 10 traps with their exit codes, 256-value stack, 64-deep calls, 256 words of memory, step and output limits. Node 22 stdlib only.

Run: `MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts`
